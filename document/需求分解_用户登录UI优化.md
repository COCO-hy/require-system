## 2. 技术栈分析

| 识别项 | 识别结果 |
|--------|----------|
| **语言/运行时** | JavaScript (Node.js) / 浏览器端 HTML5 + CSS3 |

## 3. 功能点清单

### 3.1 登录表单卡片式设计

| 项 | 内容 |
|----|------|
| **模块** | `public/index.html`（新建登录页面模板） |
| **改动点** | 创建 `public/login.html`，包含卡片容器：居中布局、圆角(border-radius)、阴影(box-shadow) |
| **影响范围** | 仅新增文件，不影响现有功能 |
| **具体样式** | border-radius: 16~20px; box-shadow 多层阴影; 背景白色/半透明; 最大宽度 420px; 垂直水平居中 |
| **验收标准** | 卡片在桌面浏览器中完美居中显示，有立体感和层次感 |

### 3.2 输入框聚焦动画

| 项 | 内容 |
|----|------|
| **模块** | `public/css/login.css`（新增样式文件） |
| **改动点** | 输入框 :focus 伪类动画：border-color 渐变过渡、轻微上移 translateY(-2px)、外发光 box-shadow |
| **影响范围** | 仅登录页面的输入框，不干涉其他表单 |
| **具体效果** | 聚焦时 border 从 `--border` 过渡到 `--accent` 色；transform: translateY(-1px)；box-shadow 0 0 0 3px accent-glow；transition 220ms cubic-bezier |
| **验收标准** | 点击输入框时看到平滑的边框颜色渐变和轻微上移动画 |

### 3.3 表单验证错误提示

| 项 | 内容 |
|----|------|
| **模块** | `public/css/login.css` + `public/js/login.js`（新增） |
| **改动点** | 用户名/密码输入框验证：空值检测、格式校验；错误时红色边框 + 错误消息文本 |
| **影响范围** | 仅登录页面验证逻辑 |
| **具体实现** | CSS: `input.error` 红色 border + red box-shadow；JS: submit 时校验，显示 `.error-message` 元素 |
| **验收标准** | 空值提交时输入框变红并显示错误提示；输入后错误自动消失 |

### 3.4 移动端适配

| 项 | 内容 |
|----|------|
| **模块** | `public/css/login.css` |
| **改动点** | @media (max-width: 768px) 和 (max-width: 480px) 断点适配 |
| **影响范围** | 仅登录页面，不干涉现有系统样式 |
| **具体适配** | 768px: padding/margin 缩小；480px: 卡片全宽、字体缩小、按钮全宽 |
| **验收标准** | 在手机尺寸视口下布局正常，可读可用 |

### 3.5 记住密码复选框样式

| 项 | 内容 |
|----|------|
| **模块** | `public/css/login.css` |
| **改动点** | 自定义 checkbox 样式替代浏览器默认样式（隐藏原生 checkbox，用 label::before 绘制美观的勾选图标） |
| **影响范围** | 仅登录页面 |
| **具体样式** | 圆形勾选框、选中时 accent 色填充、平滑过渡动画 |
| **验收标准** | 复选框显示为自定义样式，点击交互流畅 |

### 3.6 登录按钮 loading 状态

| 项 | 内容 |
|----|------|
| **模块** | `public/css/login.css` + `public/js/login.js` |
| **改动点** | 提交时按钮显示旋转 spinner + 文字变为"登录中..."，禁止重复点击 |
| **影响范围** | 仅登录页面 |
| **具体实现** | CSS: `.btn-loading` 状态含 spinner 伪元素；JS: submit 时设置 loading 状态，请求完成/失败后恢复 |
| **验收标准** | 点击登录按钮后看到 loading 动画，按钮不可用，请求完成后恢复正常 |

## 4. 代码模块分层定位

```
require-system/
├── public/                          # 前端静态资源
│   ├── login.html                   # [新增] 登录页面 HTML
│   ├── css/
│   │   ├── style.css                # [已有] 全局样式（不变）
│   │   └── login.css                # [新增] 登录页面专用样式
│   ├── js/
│   │   ├── app.js                   # [已有] 需求管理前端逻辑（不变）
│   │   └── login.js                 # [新增] 登录页面交互逻辑
│   └── index.html                   # [已有] 首页（不变）
├── server.js                        # [已有] Express 服务器（不变）
└── routes/
    └── requirements.js              # [已有] 需求 API（不变）
```

**核心原则**：新增文件独立于现有系统，不修改已有文件，确保零侵入。

## 6. 依赖与风险

| 风险项 | 等级 | 缓解措施 |
|--------|------|----------|
| 样式与现有主题不符 | 🟢 低 | 复用现有 CSS 变量体系（--accent、--bg-surface、--font-display 等） |
| 移动端适配遗漏 | 🟡 中 | 使用 @media 三个断点覆盖手机/平板/桌面 |
| 记住密码安全风险 | 🟡 中 | 仅存储用户名（不存密码），明确告知用户 |
| 浏览器兼容性 | 🟢 低 | 使用标准 CSS3 和 ES6+，支持现代浏览器 |
